# 90 天 SEO 实战计划

适用于新接手网站或要建立持续 SEO 运营的团队。90 天目标是完成基线、修复主要阻塞、建立页面/内容/权威增长系统并跑出第一轮数据，不承诺具体排名或收入。

## 启动信息

| 字段 | 内容 |
|---|---|
| 业务目标 / KPI | 自然收入、合格线索、非品牌点击、重点品类覆盖 |
| 市场 / 语言 |  |
| 重点产品 / 毛利 / 库存 |  |
| 基线周期 | 建议同比 + 最近 28/90 天 |
| 负责人 | SEO、开发、内容、设计、PR、分析、业务 owner |
| 约束 | 上线窗口、CMS、法务、开发能力、季节性 |

优先级统一用：`P0 阻塞`、`P1 高业务影响`、`P2 增长`、`P3 实验`。每项交付物都必须绑定负责人、截止日期、依赖和 KPI。

## 第 1-30 天：基线、诊断、策略

| 工作流 | 关键动作 | 交付物 | 负责人 | 优先级 | KPI / 验收 |
|---|---|---|---|---|---|
| 数据 | 接入 GSC/GA4/Bing/收入；拆品牌/非品牌、目录、国家、设备 | 基线仪表盘与 annotation | 分析 + SEO | P0 | 数据可复现，核心转化可追踪 |
| 技术 | crawl、索引、日志、robots/noindex、status、canonical、sitemap、hreflang、CWV | 问题清单与模板矩阵 | SEO + 开发 | P0 | 所有问题有证据、影响 URL、owner |
| 关键词 | 收集 GSC/客户/站内搜索/竞品/SERP，按意图聚类 | 需求库和关键词-URL 映射 v1 | SEO + 业务 | P1 | 核心产品/品类 100% 有目标意图 |
| 内容 | 盘点现有 URL：保留/更新/合并/删除/新建 | 内容 inventory 与 top 20 brief | 内容 + SEO | P1 | 高价值页都有动作与负责人 |
| 架构 | 识别孤儿页、模板冲突、分类/导航/分页问题 | 站点树与内链方案 | SEO + UX | P1 | 重点页可通过普通链接发现 |
| 外链 | 基线引用域、品牌提及、丢失链接、竞争资产 | 权威/PR 机会清单 | PR + SEO | P2 | 20 个相关机会，拒绝垃圾目标 |
| Shopify | collection/product/variant/筛选/分页/缺货/Markets/app 性能专项 | Shopify 风险表 | SEO + 主题开发 | P0/P1 | 高价值模板逐项验收 |

第 30 天决策会：业务 owner 批准 KPI、URL 映射、P0/P1 backlog、内容产能与上线节奏。

## 第 31-60 天：修复、优化、生产

| 工作流 | 关键动作 | 交付物 | 负责人 | 优先级 | KPI / 验收 |
|---|---|---|---|---|---|
| 技术 | 修 P0：索引指令、5xx/404、重定向、canonical/hreflang、sitemap；改善最差模板 CWV | 发布记录与前后 crawl diff | 开发 + SEO | P0 | P0 清零；高流量 URL 无回归 |
| 页面 | 优化高展示/高价值 collection、product、服务页的意图、title、主体、信任与 CTA | 10-30 个页面更新 | 内容 + SEO + CRO | P1 | 展示/CTR/转化建立观察基线 |
| 内容 | 发布第一批支持主题、比较/购买指南、原创经验或数据 | 4-12 个高质量页面 | 内容 + 专家 | P1/P2 | 每页有独特价值、入链、审核 |
| 内链 | 从高权威和高流量页链接重点商业页，修断链/重定向链接 | 内链变更表 | SEO + 内容 | P1 | 重点 URL 入链和深度改善 |
| 外链 | 推出 1 个可链接资产；做未链接提及、合作伙伴和定向 PR | outreach 日志与资产 | PR + 专家 | P2 | 相关引用、品牌提及、referral |
| 监控 | 建每日技术告警、每周 GSC 机会与内容看板 | 告警与周报模板 | 分析 + SEO | P0 | 异常 24 小时内被发现和分派 |

所有批量模板更改先小样本 QA，再全量发布；为每次部署写 annotation。

## 第 61-90 天：扩张、实验、固化

| 工作流 | 关键动作 | 交付物 | 负责人 | 优先级 | KPI / 验收 |
|---|---|---|---|---|---|
| 复盘 | 比较基线、同比、test/control；区分需求和执行影响 | 90 天复盘 | SEO + 分析 | P0 | 结论含不确定性和下一步 |
| 技术 | P1/P2、crawl budget、JS/第三方、schema/feed、自动 QA | CI 门禁与技术 roadmap | 开发 + SEO | P1 | 门禁只含明确错误或项目政策 |
| 关键词 | 根据真实 queries、转化和 SERP 更新映射 | 主题路线图 v2 | SEO + 业务 | P1 | 下一季度机会有商业排序 |
| 内容 | 扩大有效模板；更新/合并低效内容；建立季度维护 | 编辑日历与更新队列 | 内容 + SEO | P1/P2 | 内容按质量和转化扩张，不按字数 |
| 外链 | 放大有效资产和媒体关系，停止无回报/高风险渠道 | PR 季度计划 | PR + SEO | P2 | 相关引用域和辅助转化趋势 |
| 实验 | title/摘要、collection 信息、内链、模板体验实验 | 实验日志 | SEO + CRO | P2/P3 | 预注册假设、护栏、观察窗 |
| AI 搜索 | 记录 crawler policy、固定问题集、AI 引用/referral 基线；可选 llms.txt 实验 | GEO 实验表 | SEO + 品牌 | P3 | 不把实验项写成排名保证 |

## 90 天验收

- 所有 P0 有关闭证据；P1 有 owner 和日期。
- 核心商业主题完成关键词-URL 映射，无明显模板冲突。
- 发布/更新内容通过事实、意图、内链、技术、转化审核。
- 仪表盘覆盖业务、搜索、索引、质量；品牌/非品牌可分。
- 至少一个可链接资产和可持续宣传流程上线。
- 下一季度 roadmap 按影响、信心、成本和业务约束排序。
