# SEO 实战知识库

这套知识库把 SEO 当成一个持续运营系统，而不是“改标题、堆关键词、跑分”的清单。目标是让正确页面被发现、抓取、理解、索引并匹配正确需求，最终产生业务结果。

## 使用顺序

1. 先读 [证据等级与来源](sources-and-evidence.md)，区分搜索引擎要求、推荐实践、团队门禁和实验项。
2. 用 [战略与衡量](strategy-and-measurement.md) 定义目标、基线和 KPI。
3. 用 [关键词与 SERP](keyword-research-and-serp.md) 建立需求库和 URL 映射。
4. 用 [内容与页面优化](content-and-on-page.md) 和 [信息架构与内链](information-architecture-and-internal-links.md) 设计页面。
5. 用 [技术 SEO](technical-seo.md) 保证抓取、渲染、索引和体验。
6. 按业务类型加载专项章节，再执行 playbook 并持续监控。

## SEO 工作模型

```
需求与商业价值
  -> 页面类型和信息架构
  -> 可发现 / 可抓取 / 可渲染 / 可索引
  -> 相关性、质量、信任和差异化
  -> 搜索展示与点击
  -> 转化、收入、留存
  -> 监控、实验、更新
```

任何一层出问题都可能让后续优化无效。优先修阻塞性问题，其次做高商业价值页面，再扩大内容规模。
