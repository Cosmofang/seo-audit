# 关键词研究、搜索意图与 SERP

关键词研究的产物不是一张按搜索量排序的表，而是“需求 -> 意图 -> 页面类型 -> URL -> 商业目标”的映射。

## 研究流程

1. 定义市场、语言、受众、产品边界和转化目标。
2. 收集 seed：产品/服务、问题、用途、场景、受众、属性、材质、品牌、替代品、比较和售后。
3. 扩展数据源：GSC、站内搜索、客服/销售、评论、论坛、SERP、Google Trends、广告搜索词、竞品页面。
4. 清理与聚类：按真实意图和 SERP 相似性聚类，不只按词形。
5. 逐组检查 SERP：主流页面类型、功能、时效、本地化、品牌强度、内容角度。
6. 映射到现有 URL 或新页面；一个意图集群通常对应一个主页面。
7. 以商业价值、可赢性、需求、季节性、资源和现有权威排序。

## 意图与页面类型

| 意图 | 常见需求 | 合适页面 |
|---|---|---|
| 导航 | 找品牌、登录、具体产品 | 首页、品牌页、产品页 |
| 信息 | 学习、排错、定义 | 指南、教程、研究、工具 |
| 商业调查 | best、review、vs、alternative | 比较、购买指南、分类页 |
| 交易 | buy、price、discount、near me | 产品、collection、服务/地点页 |
| 售后 | manual、returns、compatibility | 帮助中心、政策、兼容页 |

SERP 是意图证据，不是必须复制的模板。若结果混合，说明意图可能混合；可选择主导意图，或设计能同时帮助比较与购买的页面。

## 关键词字段

最小字段：`cluster`、`query`、`market/language`、`intent`、`funnel`、`page type`、`mapped URL`、`monthly demand`、`trend/season`、`business value`、`SERP features`、`current clicks/impressions/position`、`competitors`、`priority`、`status`、`owner`。

搜索量、难度和 CPC 是工具估计。KD/DA/DR 不是 Google 指标；零搜索量不代表零真实需求。优先用 GSC、站内搜索和客户语言校准。

## URL 映射与蚕食

- 同一意图若多个 URL 同时获得相似查询展示，先判断是否真冲突，不要只因关键词重叠就合并。
- 页面意图不同可共存，例如“跑鞋”collection、“如何选跑鞋”指南和某型号产品页。
- 真冲突处理顺序：明确主页面 -> 内链与页面定位 -> 内容合并/差异化 -> 必要时 301/canonical。
- canonical 用于重复或高度相似版本，不用于替代信息架构和内容决策。

## 内容差距判断

不要只比较字数。检查：用户任务是否完成、原创数据/经验、产品覆盖、证据、媒体、更新、作者/品牌信任、交互工具、内部链接、可购买性和 SERP 展示资格。竞争优势来自更好的答案或产品，不是“比第一名多写 500 字”。

## 主题集群

建立中心页和支持页时，每页必须有独立用户任务；支持页通过上下文内链回到中心/商业页，中心页也应能发现支持页。不要为了“topical authority”批量制造没有独立价值的长尾页。
